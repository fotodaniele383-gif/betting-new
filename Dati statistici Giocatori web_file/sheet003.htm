Come leggere queste colonne
Esempio
Incontri con i dati statistici richiesti disponibili.
Aces/M
Ace per partita con statistiche di servizio disponibili.
DFs/M
Doppi falli per partita con statistiche di servizio disponibili.
1° Sv%
Percentuale di punti di servizio dove è arrivato il primo servizio.
1° Sv Pts%
Percentuale di punti vinti dopo aver effettuato un primo servizio.
2° Sv Pts%
Percentuale di punti vinti dopo aver sbagliato il primo servizio e aver effettuato un secondo.
BP salvate%
Percentuale di punti break vinti dal cameriere.
Percentuale di tensione
Percentuale di occasioni di break-point vinte dal ritornatore.
Svc Pts%
Percentuale di tutti i punti vinti durante il servizio.
Ret Pts%
Percentuale di tutti i punti vinti durante il ritorno.
Pts% totale
Percentuale di tutti i punti completati vinti.
How to read these columns
Rank
For the current season, this is the latest ranking. For past seasons, this is the year-end ranking.
Wk +/−
Ranking change since the previous ranking snapshot.
YTD Δ
Ranking change since the start of the season.
Win %
Wins divided by total completed main-draw matches.
Elo
For the current season, this is the latest TennisDB Elo rating. For past seasons, this is year-end Elo.
Set Win %
Sets won divided by total completed sets in eligible scored matches.
Set Margin
Average per-set game margin from the player's perspective. Positive values mean winning sets by more games on average.
SoS %
Strength of Schedule percentile based on opponent quality. Higher means the player faced tougher opponents.
vs Expected
Wins above or below Elo prediction over the player's last 20 matches. Positive means outperforming expectations.
